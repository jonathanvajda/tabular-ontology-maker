Important User Data NoticeData that a user inputs stays local to the user's computer, by design. Ontology settings and data can be saved in the browser ('Save Session' button), but users are encouraged to export progress ('Download RDF' button) since it cannot be otherwise recovered. This is on purpose.
This site does not receive data from a user, and therefore no user data is stored remotely on the host site. If you are interested in storing data on the cloud (on a server), please contact me (jonathan.vajda [at] gmail.com) so I know about your interest and so I can notify you if/when I add that feature.
